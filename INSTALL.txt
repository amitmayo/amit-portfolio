AMIT PORTFOLIO — HOMEPAGE RICH TEXT FIX

Bug fixed:
The homepage originally loaded rich text from the Supabase content model, then a legacy plain-text update overwrote the formatting. This caused selected words such as "Amit" to show as bold/colored in the Admin editor but not in the live homepage.

Change:
Replace assets/app.js with the included fixed version. The legacy text update now preserves existing formatting if the wording has not changed. No design, content or Supabase changes are needed.

INSTALL THROUGH GITHUB (NO TERMINAL)
1. Open https://github.com/amitmayo/amit-portfolio/tree/main/assets
2. Choose Add file > Upload files.
3. Drag the included app.js into GitHub so it replaces assets/app.js (do not upload INSTALL.txt).
4. Commit changes to main.
5. Watch https://github.com/amitmayo/amit-portfolio/actions for Deploy Portfolio success.
6. Refresh the homepage and /dan/ Admin Mode (Cmd + Shift + R).
7. In /dan/, apply formatting, Save draft, then Publish changes.

Tested with a real browser simulation (Chromium): formatting of the word Amit is now preserved and renders with font-weight 700 and deep burgundy RGB(148, 74, 92). The existing build and other website files remain untouched.
